# Release notes

What changed in each release, newest first. A release may add up to four indented bullets under its line; the app's What's new window shows them.

- **Release 7** · 22 Oct 2026: Greenhouse storage planning, Beer Soup back on the menu, and a What's new window.
  - Each crop has its own harvest size, as read in the game.
  - A storage card shows the shelf and fridge space a day's harvest needs.
  - A Replant column shows how often to replant each crop so storage doesn't fill up, with a Never left over setting.
  - Separate switches for automatic harvesting and replanting, and a warning when automatic harvesting would grow too much.
- **Release 6** · 19 Oct 2026: Release notes added.
- **Release 5** · 18 Oct 2026: Improved experience on phone screens.
- **Release 4** · 17 Oct 2026: Site verification for Google Search. Nothing changes on the screens.
- **Release 3** · 17 Oct 2026: Link previews when the planner is shared, an icon for the browser tab, and a clearer page title.
- **Release 2** · 17 Oct 2026: Visit counting with GoatCounter, which stores no IP addresses and sets no cookies.
- **Release 1** · 17 Oct 2026: First public release, up to date for Update 5: the Stock planner, Clientele matcher, Custom recipes, Greenhouse, and My venues.
